# deepflow (Client Side)

`deepflow`는 독서 중 인상 깊은 문장을 기록하고, 감성적인 카드 형태로 관리하여 나만의 독서 기록을 구축하는 모바일 애플리케이션입니다. 저는 이 프로젝트에서 **React Native와 Expo를 활용하여 iOS 최적화 모바일 클라이언트를 구현**하고, 백엔드 API와의 실시간 데이터 동기화 및 독서 세션 인터페이스를 담당했습니다.

# 설치 및 실행 방법(iOS기준)
npm install

npx expo start

앱 구동은 실제 기기로 App store에서 Expo Go 앱 설치 후, 터미널의 QR 코드를 스캔하세요

## 📖 주요 기능

### 📖 독서(Reading)
- **독서 세션 관리**: 읽기 시작부터 종료까지의 시간을 기록하고, 페이지별 머문 시간 및 돌아간 페이지(Re-reading) 데이터를 서버와 동기화하여 독서 패턴 분석.
- **인터랙티브 리딩**: 독서 중 문장을 길게 눌러(Long-press) 형광펜을 칠하거나, 즉시 저장 화면으로 이동하여 글꼴, 크기, 배경을 커스텀한 '나만의 문장 카드' 생성.
- **독서 환경 설정**: 글자 크기 및 글꼴 설정을 통해 최적의 가독성을 제공하는 개인화 환경 구축.

### 🏠 홈(Home)
- **오늘의 문장**: 랜덤으로 추천되는 10개의 구절을 통해 매일 새로운 인사이트를 얻고, 마음에 드는 구절은 즉시 저장 가능.

### 📅 마이페이지 및 기록(Archive)
- **저장한 문장 보관함**: 사용자가 저장한 모든 문장을 한눈에 관리하고, 스타일별(이미지/텍스트)로 확인.
- **독서 캘린더**: 캘린더 인터페이스를 통해 과거의 독서 기록을 날짜별로 조회하고, 특정 날짜 클릭 시 해당 일자의 독서 상세 결과(시간, 저장 문장 등)를 회상.

## 🛠 현재 진행 상태 (Status)
- **문장 저장 및 UI 인터랙션**: 완료
- **독서 세션 시간 기록**: 연동 중
- **백엔드 통신**: 실시간 연동 중이며, 서버 데이터 스펙에 맞춰 데이터 정합성 검증 및 API 구간 최적화 진행 예정입니다.

## 💻 기술 스택
- **Framework**: React Native (Expo)
- **Language**: TypeScript
- **State Management**: Zustand
- **Networking**: Axios
- **Tooling**: Expo Go (iOS 환경 기반)
